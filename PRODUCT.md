# Product

## Register

product

## Users

Developers who use multiple official Codex or ChatGPT accounts on macOS and Linux. They need to select an account explicitly, keep credentials isolated, inspect official usage limits, and manage local or remote Codex sessions without weakening Codex security defaults.

## Product Purpose

CodexAccountBridge provides a conservative CLI and native macOS interface for managing independent official Codex login environments. Success means users can understand which account and machine are active, make deliberate account changes, and retain control of cross-account disclosure without CAB proxying requests or handling token contents.

## Brand Personality

Trustworthy, precise, and native. The product should feel like a focused macOS developer utility: calm during routine inspection, explicit before consequential actions, and technically transparent about security boundaries.

## Anti-references

Do not resemble token dashboards, third-party API proxies, growth-oriented SaaS control panels, or tools that hide automatic account switching behind quota and authentication errors. Avoid decorative complexity, ambiguous status badges, and controls whose visual weight exceeds their importance.

## Design Principles

- Make account, target, and sharing state immediately legible.
- Keep routine inspection quiet and reserve emphasis for primary or consequential actions.
- Prefer familiar native controls and system symbols over custom interaction patterns.
- Explain security boundaries at the point where they affect a decision.
- Keep account selection explicit and credentials visibly isolated.

## Accessibility & Inclusion

Use native macOS controls, support keyboard and assistive-technology labels, and never communicate login, default, remote, or warning state through color alone. Keep text readable at system text sizes and provide descriptive help for compact icon-only controls.
